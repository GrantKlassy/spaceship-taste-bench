Create a complete, tasteful spaceship game in Rust that runs entirely
in a terminal.

Make the game feel intentional, polished, and enjoyable. Choose the
gameplay, visual style, controls, and scope yourself.

Requirements:
- Real-time, keyboard-controlled gameplay.
- Terminal-only: no browser or graphical desktop window.
- Use the provided Linux/Rust environment.
- You may use crates.io dependencies.
- The finished game must work without network access.
- Deliver a self-contained Cargo project in the current directory,
  including Cargo.lock.
- It must launch with: cargo run --release --locked
- Include a short README explaining the controls.

The game will be played in a 124-column by 69-row UTF-8 terminal
with 256-color support.

Work autonomously. Make reasonable decisions rather than asking
clarification questions. You may run, test, and revise your work
before finishing.

End of task prompt.
