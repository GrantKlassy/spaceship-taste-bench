# Starwake

Starwake is a real-time terminal spaceship survival game. Clear the lane, dodge incoming ships and debris, and collect cyan shield cores to restore shields and trigger short overdrive bursts.

## Run

```sh
cargo run --release --locked
```

The game is designed for a 124-column by 69-row UTF-8 terminal with 256-color support.

## Controls

- `WASD` or arrow keys: fly
- `Space`, `J`, or `Z`: fire
- `P`: pause or resume
- `R`: restart after game over
- `Q` or `Esc`: quit
